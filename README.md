This is the Vibe-Coded project made for the Civics Assignment about Animal Welfare.# 🐾 PawPoint Faisal Town

A community web app for stray animal welfare in Faisal Town, Lahore, Pakistan.

## Features

- 🗺️ **Bowl Map** — Interactive OpenStreetMap showing active feeding bowl locations in Faisal Town. Admin can add or delete bowl points directly on the map.
- 🤝 **NGO Donation Board** — Lists partner NGOs with donation progress bars and contact/payment info.
- 🏠 **Find Home** — Browse stray animals available for adoption with health tags and NGO info.
- 📋 **Food Guide** — Safe and unsafe food lists for dogs and cats, with a scannable QR code to print and attach to bowl stations.

## Tech Stack

- React + Vite
- TypeScript
- Tailwind CSS
- React Router
- Leaflet.js + OpenStreetMap
- shadcn/ui

## Getting Started

```bash
pnpm install
pnpm dev
```
